# My Professional Portfolio 🚀

A responsive, high-performance personal portfolio built to showcase my journey as an IT student and aspiring software developer.

## 🌐 Live Demo
[View my portfolio live on GitHub Pages](https://sqwazy.github.io/MyPortfolio/)

## 🛠️ Tech Stack
* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **API Integration:** EmailJS (Client-side email handling)
* **Deployment:** GitHub Actions & GitHub Pages
* **Operating System:** Developed on Linux Mint 🌿

## ✨ Key Features
* **Custom Animations:** Smooth scroll reveals using the `IntersectionObserver` API.
* **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop displays.
* **Functional Contact Form:** Directly sends emails to my inbox without a backend server using the EmailJS SDK.
* **Optimized Performance:** Locally hosted libraries to ensure fast load times and high reliability.

## 📂 Project Structure
* `index.html`: The structural backbone of the site.
* `style.css`: Custom styling and responsive layouts.
* `javascript.js`: Core logic, animations, and API handlers.
* `email.min.js`: Locally hosted EmailJS library for production stability.
